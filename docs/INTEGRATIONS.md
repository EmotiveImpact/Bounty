# Integration verification register

What was checked, how, and what still needs credentials or permission. Checks were run from the development container on 31 October 2026 (UTC). No real partner credentials were configured, so no paid or credentialed provider has been verified with data. A probe with a dummy credential only confirms the endpoint, the authentication scheme and the shape of the error the adapter must handle.

The adapters live in `server/sources.mjs`; the tests that pin each request shape and mapping are in `server/sources.test.mjs` and `server/evidence.test.mjs`, using the example files in `server/fixtures/sources/`.

## Re-running the checks

- Open Prices: `BOUNTY_DATA_DIR=$(mktemp -d) npm run worker -- --pages 2`, then open Sources.
- Each credentialed provider: set its variable in `.env` and run the acceptance command above. The run appears under Recent import runs with its row count or the upstream error message, never the credential.
- `npm test` runs every adapter test offline with injected responses.
